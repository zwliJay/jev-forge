## Mind2Web

The recorded JevForge training recipe uses transformed annotations derived
from [Mind2Web](https://github.com/OSU-NLP-Group/Mind2Web), sourced through
`LangAGI-Lab/Mind2Web-axtree-cleaned-lite`.

Mind2Web is licensed under the Creative Commons Attribution 4.0 International
license. Copyright and attribution remain with the Mind2Web authors. The
Mind2Web maintainers ask users not to redistribute unzipped official test-set
files online. No raw or unzipped Mind2Web data is included in the JevForge
source repository. The static replay contains a small transformed sample with
the upstream attribution retained; it is not a replacement for the dataset.

## Qwen3 configuration and tokenizer assets

JevForge uses the Qwen3-0.6B architecture configuration and tokenizer assets
from [Qwen/Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B), distributed
under the Apache License 2.0. This JevForge checkpoint initialized the backbone
from configuration and did not load the pretrained Qwen backbone weights.
