# JevForge mixed checkpoint: complete English S1MB evaluation

The unchanged JevForge architecture was trained on 8,000 mixed decisions for
one epoch and evaluated on all 137 English S1MB benchmarks. All 26,269 decisions
succeeded, with zero failures and zero abstentions. Official raw-result validation,
package validation and the complete-category PR report passed. These are author-run
measurements; a leaderboard PR has not been submitted or accepted.

| Baseline-adjusted score (0–100) | Full English | Diverse/Contextual subset |
|---|---:|---:|
| Noul | 16.46 | 7.00 |
| Choice | 20.74 | 51.49 |
| Score | 8.26 | 5.40 |

The equal mean of the three full-category task scores is **15.16**.
These are clipped, baseline-adjusted skill scores, not raw accuracy. Official
`task_score` gives equal weight to eligible benchmarks within each task and excludes
target-degenerate benchmarks after checking complete coverage. No new Borda rank or
superiority over Jev is claimed without a complete reference comparison. Noul and
Score generalization remain weak.

## Source exposure and limitations

Training used 4,800 Open-Jev, 2,000 Mind2Web and 1,200 other decisions, plus
300 independent dev and 150 calibration decisions. The [training recipe](MIXED_TRAINING.md)
and published manifests pin source snapshots and source terms. All 8,450 retained
decisions were audited against actual source rows. Evaluation-state hashes were
used only for exclusion; evaluation labels and scores were not used for training,
checkpoint selection or calibration. This is not comprehensive semantic decontamination.

The submission metadata declares **67 benchmark-level same-source-family exposures**,
including source-train-derived dev/calibration data. These tasks are not unseen-domain
baselines. Base-pretraining exposure is unknown. No Japanese evaluation or
Japanese source-separation claim is made.

The first evaluation attempt stopped while recording the first benchmark because
the evaluator distribution metadata was missing; no result file or metric was saved.
Installing the same pinned evaluator with `--no-deps` fixed it. The full run was
then restarted with identical model/data/settings, and both logs were retained.

The canonical submission folder is `AndeyTait__JevForge-0.8B`, containing 137
compressed results and `metadata.json`. The user submits the Dataset PR to
`hotchpotch/s1mb-result`; earlier measurements remain in Hub history. Datasets,
base/final models, offline W&B, logs and result packages were backed up locally
with hashes and recovery checks. No cloud W&B sync is claimed.
